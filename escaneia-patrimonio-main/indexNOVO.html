Ativar a câmera

Este app usa a câmera para ler o QR Code e o código de barras da etiqueta de patrimônio, e para registrar a foto do item automaticamente.

Caminho mais direto
  1. Toque no botão abaixo para copiar o endereço das configurações de câmera do Chrome.
  2. Cole esse endereço na barra de endereço do Chrome (onde normalmente você digita um site) e abra.
  3. Deixe a opção "Os sites podem pedir para usar a câmera" ativada.
  4. Procure claude.ai na lista de sites bloqueados e mude para Permitir (ou remova da lista).

chrome://settings/content/camera

Ainda não pede permissão? Veja mais 2 coisas para checar
  1. Permissão do próprio Android: Ajustes do Android → Apps → Chrome → Permissões → Câmera → deixe em "Permitir".
  2. Reset completo do site: no Chrome, abra chrome://settings/content/all, procure claude.ai, toque nele e em "Limpar e redefinir" — isso apaga todas as permissões salvas desse site e força o Chrome a perguntar de novo, do zero.
Isto não é uma configuração do seu celular

Testei e confirmei: esta prévia dentro do Claude bloqueia o acesso à câmera por política de segurança da própria plataforma (o conteúdo roda dentro de um quadro isolado que não tem permissão de câmera liberada). Isso vale para qualquer aparelho — não há ajuste no Chrome ou no Android que resolva isso a partir daqui.

A solução é publicar este mesmo arquivo fora do Claude, num link próprio — o app funciona exatamente igual, só muda o endereço. Combine com quem está te ajudando a hospedar o arquivo (por exemplo, no Netlify ou GitHub Pages) para gerar esse novo link.
